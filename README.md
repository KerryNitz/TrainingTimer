# TrainingTimer

TrainingTimer provides timers for structured exercise routines:
- EMOM10: an **E**very **M**inute **O**n the **M**inute timer for 10 minutes, with a lead in timer of 15 seconds and beeps 3 seconds before each minute
- EMOM20: an **E**very **M**inute **O**n the **M**inute timer for 20 minutes, with a lead in timer of 15 seconds and beeps 3 seconds before each minute _(not yet implemented)_
- TUT3030: a **T**ime **U**nder **T**ension timer with 30 seconds on, 30 seconds off for a configurable number of sets, with a lead in timer of 15 seconds and beeps 3 seconds before each interval _(not yet implemented)_
- TUT6060: a **T**ime **U**nder **T**ension timer with 60 seconds on, 60 seconds off for a configurable number of sets, with a lead in timer of 15 seconds and beeps 3 seconds before each interval _(not yet implemented)_
- TUT9030: a **T**ime **U**nder **T**ension timer with 90 seconds on, 30 seconds off for a configurable number of sets, with a lead in timer of 15 seconds and beeps 3 seconds before each interval _(not yet implemented)_

These timers are especially suitable for kettlebell and heavy club routines.
